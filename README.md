## 技术说明

- 单文件 `index.html`，纯静态、零外部依赖（二维码已内嵌）
- 顶部吸顶导航，自动显示当天日期
- 卡片式版式，自适应手机 / 平板 / 电脑
- 悬浮按钮一键返回顶部

## 部署

将 `index.html` 上传至 Cloudflare Pages 即可，无需构建步骤。
